# Practical 04 — Understanding Data with Graphs

Explores the teaching ratings data through duplicate checks and comparisons shown with graphs.

## Topics

- Duplicate cases and age summaries
- Evaluations in lower- and upper-division courses
- Age and evaluation scores
- Comparisons by gender and tenure

## Dataset

`TeachingRatings.csv` is in the repository root; use `../TeachingRatings.csv` from this folder.
