# Practical 08 — Decision Trees and Maximum Depth

Builds a decision-tree classifier for diabetes data and examines how model depth and split criteria affect the tree.

## Topics

- Feature selection and train/test split
- Decision-tree classifier
- Tree visualization
- Entropy, information gain, and Gini index
- Feature importance

## Dataset

- `diabetes.csv` is stored in the repository root; the notebook reads it from `../diabetes.csv`.
