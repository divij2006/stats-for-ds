# Practical 06 — T-Tests, ANOVA, and Chi-Square

Applies several statistical tests to questions about the teaching ratings data.

## Topics

- T-test by gender
- ANOVA by age group
- Chi-square test for tenure and gender
- Correlation of evaluation and beauty scores

## Dataset

- `TeachingRatings.csv` is stored in the repository root; the notebook reads it from `../TeachingRatings.csv`.
