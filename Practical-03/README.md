# Practical 03 — Descriptive Statistics

Uses the teaching ratings data to compare groups and choose clear summaries and plots.

## Topics

- Minority status and tenure
- Age comparisons by tenure
- Choosing and plotting variables
- Vertical and horizontal bar charts
- Median evaluation score

## Dataset

- `TeachingRatings.csv` is stored in the repository root; the notebook reads it from `../TeachingRatings.csv`.
