# Practical 02 — Statistics Foundations with a Rating Dataset

Introduces the rating data and summarizes its variables with descriptive statistics and visual comparisons.

## Topics

- Cross-sectional data
- Mean, median, minimum, and maximum
- Descriptive summary tables
- Histogram of beauty scores
- Comparisons by gender and tenure

## Dataset

- `TeachingRatings.csv` is stored in the repository root; the notebook reads it from `../TeachingRatings.csv`.
