# Practical 12 — Deterministic Model

Implements the Metropolis algorithm from scratch and uses it on the sunspot data to compute deterministic quantities from the model parameters.

## Topics

- Metropolis algorithm
- MCMC sampling for a gamma model
- Deterministic quantities (mean, variance, standard deviation, probability of a high month)
- Comparing model results with the real data

## Dataset

- `sunspots_1749_2018.csv` is stored in the repository root; the notebook reads it from `../sunspots_1749_2018.csv`.

[Open `Practical_12.ipynb`](Practical_12.ipynb).
