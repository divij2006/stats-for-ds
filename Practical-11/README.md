# Practical 11 — Monte Carlo and MCMC

Models historical monthly sunspot counts with a gamma distribution and uses MCMC to estimate model parameters.

## Topics

- Sunspot time series
- Gamma distribution
- Monte Carlo simulation
- MCMC traces, burn-in, and parameter estimates

## Dataset

- `sunspots_1749_2018.csv` is stored in the repository root; the notebook reads it from `../sunspots_1749_2018.csv`.

## Notebook

[Open `Practical_11.ipynb`](Practical_11.ipynb).

Run the notebook with Python and Jupyter. Its saved cell outputs are part of the notebook.
